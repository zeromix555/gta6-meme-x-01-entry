## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only, no network, deterministic) copies `POST.json` to the output directory, where the gate reads it. The post itself is the entry — the house reads it from X.
